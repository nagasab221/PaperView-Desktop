PaperView for Linux
===================

A free reader for PDFs and ebooks. No ads, no accounts.

Install (no root needed):   ./install.sh
Remove:                     ~/.local/opt/paperview/uninstall.sh

Or run it straight from this folder: ./paperview
(keep paperview and libpdfium.so together).

Project page: https://github.com/nagasab221/PaperView-Desktop
Licences of PaperView and what it includes are in licenses/.
